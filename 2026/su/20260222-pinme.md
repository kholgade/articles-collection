## [Software of the Week] PinMe: Decentralized Hosting Service

Links get deleted, websites get shut down, domains disappear. How can content be **permanently** preserved on the internet?

There's now a solution: IPFS (InterPlanetary File System). Through a distributed protocol, content is shared across all nodes, and the URL is the content's hash.

So, once content is uploaded to IPFS, it cannot be modified (because the hash would change) and cannot be deleted (because other nodes retain copies).

[PinMe](https://pinme.eth.limo/), introduced today, is exactly such an IPFS hosting tool.

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026022202.webp)

You can use it to upload any file to IPFS. Upload a static website, and it's theoretically permanently accessible. No one (including you) can delete, modify, or shut it down. Any IPFS gateway can open and browse it.

PinMe assigns an ENS domain pointing to your uploaded content. This domain is written to the Ethereum blockchain and is also permanent.

It provides 1GB of free storage. Larger storage and custom domains require payment.

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026022203.webp)

Files can be uploaded via the web interface, or you can use its open-source [command-line publishing tool](https://github.com/glitternetwork/pinme) to publish to IPFS with a single command. That tool already has 2,800 stars. If you need to preserve content permanently, give it a [try](https://pinme.eth.limo/).
