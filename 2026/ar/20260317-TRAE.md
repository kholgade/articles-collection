# AI IDE Meets Native Linux: TRAE's Linux Version Is Here

Today, I'm helping [TRAE](https://www.trae.cn/) share a brief announcement.

Linux users now have another AI IDE option — the [TRAE Linux version](https://www.trae.cn/ide/download) is now available.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031801.webp)

Why is this worth noting?

It goes back several years. When AI coding first emerged, VS Code's Copilot plugin was the only tool available — it could complete code and generate functions based on text descriptions. Everyone was amazed: "Wow, this is incredible!"

Not long after, ByteDance quickly launched a similar plugin called MarsCode. I was an early user of this plugin and have been following their product developments since then.

By early 2025, AI coding had advanced rapidly. Plugins, limited by their host environments, were increasingly insufficient. ByteDance began working on an independent, AI-specialized IDE — that's TRAE.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031706.webp)

TRAE initially only had Windows and Mac versions, with no Linux version. I found this odd at the time — it's built on Electron, which supports Linux.

The team explained that TRAE's core components — AI inference engine, context indexing, etc. — are self-developed and written in Rust, Go, or C++ for performance. They need separate compilation, testing, and optimization for Linux, which takes significant engineering effort.

Additionally, Linux desktop environments are heavily fragmented, involving GPU driver (Wayland vs X11) hardware acceleration — all requiring manpower.

So their initial plan was to prioritize AI IDE features and work on the Linux version later.

However, the demand for a Linux version never stopped. The team noticed this and was equally eager. Despite limited development resources, they eventually decided to schedule it and allocate resources.

Finally, this week, the Linux version was officially released. TRAE now has clients for all three major platforms: macOS, Windows, and Linux.

Whether you're a backend, full-stack, DevOps, ML, or embedded engineer, regardless of your platform, you can now use TRAE for AI coding.

But with many Linux AI IDEs already available — Cursor, Windsurf, Antigravity internationally, plus traditional VS Code and JetBrains — you might ask, why use TRAE?

Here are some TRAE features worth considering.

**(1) Native Linux Support**: TRAE's Linux support is very comprehensive.

The installation package comes in three formats: deb (Debian/Ubuntu), rpm (RHEL/Fedora), and tar.gz (universal archive for any distribution), supporting both x64 and arm64 architectures.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031803.webp)

Additionally, it's adapted for both Linux desktop environments (Wayland and X11), providing smooth and stable operation.

**(2) Unified Experience**: The Linux version is identical to Windows/Mac versions — no differences. Features are complete, including MCP management interface shown below.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031802.webp)

**(3) SOLO Orchestrator**: TRAE comes with SOLO mode for orchestrating multiple AI Agents, allowing multiple Agents to run simultaneously. As far as I know, TRAE is the first AI IDE to offer this feature.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031806.webp)

**(4) VS Code Plugin Compatibility with One-Click Import**: TRAE supports the VS Code plugin marketplace and offers one-click import of VS Code/Cursor configurations — zero migration cost.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031805.webp)

**(5) Free Models**: TRAE comes in domestic and international versions. The international version uses foreign models and requires payment; the domestic version uses domestic models and is free for personal use.

Currently, the domestic version supports the domestic models shown below, all free. However, during peak usage, you may need to queue.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031707.webp)

Linux users who want to try it can [download](https://www.trae.cn/ide/download) from their official website.
