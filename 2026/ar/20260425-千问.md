## III. Global Activation

After this update, you can use a shortcut key to globally activate Qwen.

What is global activation? It means **regardless of your current environment or which window you're in, you can bring up Qwen with a shortcut key**.

This allows you to quickly call AI at any time, greatly facilitating daily use.

The default shortcut is the right Alt key (Windows) or the right Command key (Mac). You'll remember it after a few uses.

## IV. Smart Voice Input

Holding the shortcut key activates smart voice input.

This feature uses the computer's microphone to have the AI model process received voice.

When activated, a prompt appears at the bottom of the screen (shown below).

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026042607.webp)

Hold the shortcut key, and Qwen continuously recognizes the voice input. Release the key to stop input.

If the cursor is in an input box, the recognized text is inserted at the cursor position.

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026042801.webp)

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026042803.webp)

Based on my testing, **its recognition accuracy is very high**. The image above shows the recognition result of mixed Chinese-English speech — no typos, requiring基本上 no secondary corrections. You can use it as a reliable English speech-to-text tool.

Additionally, the AI model processes the text, automatically removing filler words, correcting speech errors, optimizing expression, and presenting it in a structured format.

## V. Voice Commands

### 5.1 Asking Questions

Double-clicking the shortcut key allows you to ask Qwen questions directly. A different prompt appears at the bottom of the screen.

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026042604.webp)

Compared to the voice input in the previous section, there's an extra line of prompt text inviting you to ask a question directly.

After speaking your question, press the shortcut key again to submit the input. It opens a small window (shown below) to answer your question.

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026042605.webp)

You can also directly look up information or continue asking follow-up questions in this small window.

Besides voice questions, you can also select text and double-click to have it explained. Results come quickly.

### 5.2 Voice Commands

Double-clicking the shortcut key does more than just ask questions — you can also issue voice commands to AI.

Any type of command works: ask Qwen to research information, translate, take notes, make PPTs, organize spreadsheets — efficiency multiplies.

At this point, it's best to enable the "Recognize Screen" option in Settings, allowing it to see the screen (shown below).

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026042606.webp)

This option includes screen content as context for the model, improving response relevance.

Below are some common scenarios I tested.

If you need AI assistance for computer-based office work or studying, give this Qwen desktop version a try — zero barrier, easy to use, and free. Local installation is definitely more convenient than using the [web version](https://www.qianwen.com/).
