# Mysterious Model "Space Bunny" Tops OpenRouter — a Quick Review of the Free LLM

## I. The Mysterious "Space Bunny"

A couple of days ago, an anonymous model called Space Bunny suddenly shot to the top of the daily call rankings on [OpenRouter](https://openrouter.ai/stealth/space-bunny-alpha) (below) and [OpenCode](https://opencode.ai/zh/data/unknown/space-bunny).

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092701.webp)

This immediately caught my interest. Where did this mysterious model come from? It tops the charts the moment it appears, and its developer is still a secret.

Its API is open for anyone to call, with no restrictions. So I decided to test it and see just how strong this "Space Bunny" really is.

This article shares my test results. If it turns out to be good, everyone can follow along and enjoy the free ride together.

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092702.webp)

I read some reviews from overseas users. Overall they were positive, saying its coding ability is very strong.

> [User A](https://www.threads.com/@marc.uyyy/post/DdsZ8pXD0gV): I used it to make a zombie shooter game. The output quality is about the same as GPT models — really good performance (below).

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092703.webp)

> [User B](https://x.com/heyfredds/status/2103901897983729960): I gave Space Bunny a prompt on OpenCode: make me an endless runner game with parallax scrolling, particle effects, sound effects, and a scoring system.
>
> Just that one prompt — no engine, no framework, no assets, no tutorial — and it produced a fully playable game with zero code! (below)

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092704.webp)

Finally, [someone](https://x.com/marcthecreatorr/status/2103486103831339269) compared it with GPT-6 Astra by building a 3D Japanese garden scene.

Astra is widely considered the world's best at 3D generation, but judging by the results, its advantage over Space Bunny is not large.

## II. Model Characteristics

According to [OpenRouter](https://openrouter.ai/stealth/space-bunny-alpha), Space Bunny's technical characteristics are:

> - Extremely fast inference speed
> - Strong coding ability
> - Adjustable reasoning difficulty
> - 1M context
> - Multimodal

That looks like the configuration of a flagship model.

The official listing puts extremely fast speed first. OpenRouter's statistics show an average speed of 96 tokens per second (below).

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092705.webp)

That is decent — on par with fast Flash models. It is a little faster than GLM 5.3 Flash, but a little slower than DeepSeek V4.1 Flash, which is known for its speed.

If Space Bunny really is that fast, it means the model is well suited to everyday use. Current models handle ordinary coding tasks without trouble, so the faster the generation, the more working time you save.

Below is a quick test to see whether this free model is really as strong as overseas users say.

## III. Coding Tests

I tested Space Bunny alongside GLM 5.3 Flash and DeepSeek V4.1 Flash on two coding tasks.

I used OpenCode, keeping the reasoning level at the default setting — maxing it out would take far too long.

### 3.1 Angry Birds

The first is my standard test: have the model generate a 2D web game, "Angry Birds".

Getting all the details right in this game is quite difficult. The prompt is [here](https://github.com/ruanyf/ai-test-case#case03).

Space Bunny

GLM 5.3 Flash

DeepSeek V4.1 Flash

Among the three models, GLM 5.3 Flash had problems. Although it ran, it did not implement the game logic, and there were bugs when playing.

The other two models did very well, fully implementing the game logic. After a bird hits a target, special effects appear too — Space Bunny in particular produces a strong shaking effect that really feels like an arcade game.

### 3.2 Three-Dimensional Rubik's Cube

The second test is to generate a 3D Rubik's cube that automatically rotates back into place. The prompt is [here](https://github.com/ruanyf/ai-test-case#case09).

Space Bunny

GLM 5.3 Flash

DeepSeek V4.1 Flash

All three implementations are acceptable, but Space Bunny is the most capable. It displays the symbolic notation for each rotation (bottom right of the page). It can not only rotate automatically but also let you drag with the mouse to manually rotate each layer of the cube — something the other two implementations cannot do.

## IV. Vision Test

Space Bunny is a multimodal model, meaning it has visual understanding.

I found two images and asked it to compare the differences and mark them with red circles.

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092706.webp)

> [Prompt] Compare the differences between pic1.jpg and pic2.jpg, and mark the differences with red circles on pic1.jpg.

Below is its result. It correctly marked all seven differences.

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092707.webp)

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092708.webp)

Then I asked it to generate a Python script that can compare the differences between any two images.

> [Prompt] Write a Python script that reads two image files from the command line, compares the visual differences between them, and then generates a new image file based on the first image file, marking all differences with red circles.

I posted [the script's code](https://gist.github.com/ruanyf/2fa1139722ad4cf80156b54cd863a036) so you can try it locally. Usage:

> $ python3 spotdiff.py p1.jpg p2.jpg

## V. Summary

From these simple tests, I feel the model's coding ability is quite good — certainly not inferior to GLM 5.3 Flash and DeepSeek V4.1 Flash.

It is currently free to use, so you might want to try it soon.

Based on past experience, such anonymous models are usually the work of well-known model companies — a way to test market reaction and fine-tune things before an official launch.

I think it is probably a domestic (Chinese) model. Considering that all the major domestic model companies have released new models recently, and only MiniMax and Kimi have yet to ship, Space Bunny is likely from one of them. Perhaps we will see the official version and benchmark scores very soon.
