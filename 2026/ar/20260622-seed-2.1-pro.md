# The Seed Model Behind Doubao Has Been Upgraded Again

## I. Introduction

When using [Doubao](https://www.doubao.com), have you ever noticed the model behind it?

I imagine few people pay attention — the entire website only mentions "About Doubao Large Model" once in the Settings section.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062301.webp)

Clicking it takes you to ByteDance's cloud service platform "[Volcengine](https://www.volcengine.com/product/doubao)", where the Doubao large model API is available externally.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062401.webp)

This model is ByteDance's self-developed product, officially named Doubao-Seed-xxxx.

Seed is ByteDance's AI team — the recently viral video model Seedance comes from this team. The Doubao large model (Seed foundation model) is their flagship model.

I've always been curious: compared to other models, what level is the Seed model at, and what can it do? After all, it determines Doubao's ceiling.

## II. Seed 2.1 Pro

Yesterday, I saw on social media that Volcengine had released the latest Seed 2.1 series models at its annual conference.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062302.webp)

This series includes two models, with the strongest being Seed 2.1 Pro. It went live the same day on TRAE and Kousi (Coze) at full scale, with its API also [opened via Volcengine Ark](https://console.volcengine.com/ark/region:ark+cn-beijing/overview?briefPage=0&briefType=introduce&type=new) for external service. Just before publication, Doubao's [latest announcement](https://mp.weixin.qq.com/s/Sb-NMXTrWFQES1EDO_Gr2g) launched a professional version that fully uses the Seed 2.1 model for office tasks.

The [release report](https://mp.weixin.qq.com/s/a-eevQvWVAYwZQeFi1ZomA) makes it clear that this model differs from others. Typically, models have their own strengths — some excel at programming, some at reasoning and analysis, some at image generation.

But Seed 2.1 Pro is different — **it's a balanced model**. "Balanced" means it can handle various tasks and performs reasonably well at each. This makes perfect sense — it powers Doubao, which is positioned as a general-purpose daily AI application. Naturally, the underlying model needs balanced capabilities.

The release report explicitly states that this version improves coding and agent capabilities while maintaining leading VLM (vision) capabilities.

For ordinary users, if a model simultaneously achieves these three capabilities, it can meet over 90% of daily needs without switching models. You can use it for everyday tasks and only temporarily switch to specialized models for particularly difficult, domain-specific tasks.

I accessed the API immediately that day and tested all three capabilities.

## III. Coding Capability

I first tested Seed 2.1 Pro's coding capability.

While I was testing, the foreign model evaluation site arena.ai had already released rankings. On the [WebDev leaderboard](https://arena.ai/leaderboard/code/webdev), Seed 2.1 Pro ranked 8th worldwide.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062312.webp)

This ranking means Seed 2.1 Pro's web development capability is very strong. Only two domestic models made the top ten; the rest are foreign flagship models.

According to this ranking, its coding capability is comparable to Claude Opus 4.6 (released February 2026), slightly behind Opus 4.7 (released April 2026).

I used my usual [web programming test questions](https://github.com/ruanyf/ai-test-case) to test its web development ability, facilitating comparison.

(1) Web Refactoring Test: Refactor a basic webpage. Its generated results:

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062314.webp)

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062315.webp)

This page looks solid — no obvious issues. It likely used a Skill template, making the page very standardized. While somewhat plain, for business websites, following best practices is the best result.

(2) Web 3D Animation Test: Celestial Simulator

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062316.webp)

The generated simulator looks good overall — clean interface, easy to use, smooth animation. The downside is that the celestial bodies are 2D, not 3D — functional but not very realistic.

(3) Web Game Test: Angry Birds

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062317.webp)

From these tests, Seed 2.1 Pro's frontend UI capability is solid — perfectly presentable. As for other coding capabilities, especially backend programming, I didn't test due to time. I can only say that if it matches overseas evaluations and is comparable to Opus 4.6, it's sufficient for daily use.

It's generally believed that Claude Sonnet 3.7 and Claude Opus 4.6 represent the inflection point where large models move from lab to production. Now, Seed 2.1 Pro has also reached this point, moving toward production-grade code generation.

## IV. Agent Capability

Agent capability refers to the model's ability to operate a computer on behalf of the user.

AI agent tools like OpenClaw/Hermes are best paired with models that have strong Agent capabilities, allowing them to analyze and think at the underlying level, issue instructions, and let the Agent software execute.

In early June, Doubao launched a "Task Mode," which in retrospect was preparation for Seed 2.1 Pro.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062304.webp)

This task mode is essentially Agent mode, transforming Doubao into an OpenClaw (or Hermes) to operate the computer and complete specific tasks.

It comes in web and local versions, both powered by Seed 2.1 Pro. The difference is that the local version directly operates your personal computer, while the web version operates a virtual machine system on the server.

Since I was mainly testing the model, I didn't test Doubao's local Agent function — just the web version's office task processing.

(5) Word File Test

On the Doubao website, click "New Office Task" on the left and enter the task description: "Put the Weibo trending topics screenshot into a Word file."

Doubao opens Weibo in a cloud VM, creates a screenshot, and generates the Word file. The page shows each step's progress in real-time.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062305.webp)

After the Word file is generated, the page provides a download link.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062306.webp)

The Word file contains a webpage screenshot.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062307.webp)

The entire task execution process was very clear, and results were easily obtained.

(6) PPT Generation Test

I uploaded a company's quarterly report (PDF) and financial statements (Excel), asking Doubao to extract key information and generate a PPT file — testing the model's ability to analyze materials and generate reports.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062308.webp)

> Combine the quarterly report and income statement to generate a PPT file. Use plain language and visual graphics to explain the company's development situation.

Below is the PPT generated by Doubao — quite good, easier to read than the original materials.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062309.webp)

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062310.webp)

In summary, Seed 2.1 Pro's Agent capability performed better than I expected. It has built-in Office file processing capability, and combined with Doubao's VM, it runs very smoothly with good user experience.

## V. Visual Capability

Visual capability refers to the model's ability to understand images and video. Only multimodal models have visual capability — pure text models lack this.

Seed models' visual capability is said to have been leading. I had tested other models' visual capabilities a few days ago, so I directly reused the same questions. I had Claude Code access Seed 2.1 Pro's API and simply dragged videos or images into the prompt box.

(7) Image Understanding: How many red blocks are in the image below?

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026060311.webp)

Seed 2.1 Pro's response:

> There are 5 red blocks in the image:
> 1. A red five-pointed star block outside the left side of the wooden board
> 2. A red cube block placed on top of the board
> 3. A red five-pointed star block inserted into the board's hole
> 4. A red cube block inserted into the board's hole
> 5. A red semi-circular/elliptical cylindrical block outside the right side of the board, in front of the green cylinder

Not bad — it gave not just the count, but the exact shape and position of each block.

(8) Video Understanding Test: What animal appears at [this video's](https://www3.cde.ca.gov/download/rod/videosample1.html) 0:16 mark?

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026060313.webp)

Seed 2.1 Pro's response:

> At 0:16 in the video, the character appearing is Flaps from the open-source 3D animation "Big Buck Bunny" — a chubby, cartoonish purple-gray bird with fluffy purple-gray feathers, an orange-yellow beak, big eyes, and orange little claws. It's one of three mischievous animal characters in the film.

It not only described the scene but also identified which animation film the character is from.

(9) Video Page Recreation: Recreate the [ink wash effect](https://x.com/hayashimon1/status/2064658158698782873) from this video, showing ink naturally diffusing, flowing, and blending on paper.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061408.webp)

This question is quite challenging — the original animation was generated by the Fable 5 model, with random animation effects. Below is a screenshot of Seed 2.1 Pro's result, generated quite quickly.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026062303.webp)

As you can see, it replicated the UI and produced the ink droplet flow effect, but lacked the natural, ethereal feel of the original video. This is likely because it frame-by-frame replicated the original video rather than using a random droplet flow algorithm. However, purely from a video understanding perspective, it did follow the original video faithfully.

From these tests, Seed 2.1 Pro's visual capability is quite good — understanding images and video is no problem at all.

## VI. Conclusion

These are the simple tests of Seed 2.1 Pro's three major capabilities — vision, agent, and coding.

Its performance is indeed balanced — competent in every aspect. I think one highlight worth noting is its Agent capability. Considering Doubao's massive user base, combined with Doubao's Task Mode, the market is actually larger than OpenClaw/Hermes, offering developers more opportunities.

I'll continue testing it in daily programming. You can try it too — Volcengine's documentation has various [API integration methods](https://www.volcengine.com/docs/82379/2160841?lang=zh) for third-party tools.
