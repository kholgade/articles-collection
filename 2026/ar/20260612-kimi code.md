## IV. The /goal Command

Kimi Code also recently added support for the `/goal` command. I think this is an important feature worth testing.

The `/goal` command sets a specific target for the large model — once the target is achieved, the model stops running immediately.

The reason for introducing this command is that prompts are often too vague — just a general description — causing the model to overthink, initiate multiple rounds of iteration, constantly ask for user confirmation, wasting time, effort, and money.

With the `/goal` command, the large model has a clear target and can theoretically run autonomously without user intervention, stopping automatically once the preset condition is met.

My test was simple. I found a very large image (shown below), with a resolution of 6629 × 5504 pixels, taking up 2.1 MB.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061409.webp)

Then I entered the following prompt:

> /goal Resize this image so its file size is just under 120KB.

Note that the prompt starts with `/goal`, followed by a very specific target.

Kimi Code will ask you to confirm whether you allow it to run completely autonomously.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061401.webp)

Select the first option "Switch to Auto and start" to fully authorize Kimi Code — no approvals needed from you; you can walk away and do other things.

Here's the result:

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061402.webp)

> ● Image resizing complete.
>
>   • Original: 6629 × 5504 pixels, ~2.1 MB
>   • After resize: 948 × 787 pixels, 122457 bytes (~119.59 KB)
>   • File path: /Users/ruanyf/del-202606/demo.jpg
>
>   Final file size is just under 120KB, verified by python3 file size check.

It reduced the image resolution to 948 × 787 pixels with a size of 119.59KB — exactly meeting the "under 120KB" requirement.

The entire process required no manual intervention — very smooth. If you need a large model to run a task for an extended period, I highly recommend using the `/goal` command.

## VI. Kimi Datasource

Most of Kimi Code's features are the same as Claude Code's, but it also has some exclusive features.

One of my favorite features is the [Kimi Datasource plugin](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/plugins.html#kimi-datasource).

> Kimi Datasource is Kimi Code's official data plugin. It supports querying financial market data, macroeconomic indicators, company registration records, academic literature, and Chinese laws and regulations using natural language — no need to manually call APIs or register data accounts. (From the official website)

It's a data source plugin that connects to databases like Tonghuashun and Tianyancha, providing free access to real-time stock prices, financial reports, academic papers, etc. — very practical.

Installation is simple: enter `/plugins`, select Marketplace to enter Kimi's plugin store, and choose kimi-datasource.

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061403.webp)

Then enter `/reload` to activate the plugin.

When using it, enter `/kimi-datasource [your question]` to query papers, financial reports, and company information. Here are a few examples:

(1)

> /kimi-datasource Latest research on weight loss drug side effects

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061404.webp)

(2)

> /kimi-datasource Kweichow Moutai's latest income statement

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061405.webp)

(3)

> /kimi-datasource Who are ByteDance's shareholders?

![](https://cdn.beekka.com/blogimg/asset/202606/bg2026061406.webp)

This plugin can feed the latest data into large models and supports multiple data sources — recommended.

After these tests, I have a very positive impression of Kimi Code — it's a very useful coding agent that can indeed replace Claude Code.

As for the Kimi K2.7 Code model it pairs with, as a trillion-parameter model, it has strong coding capabilities, runs very smoothly, and successfully completed various tasks.

What impressed me most was its relatively economical token consumption — all the tests above only used a small portion of my membership quota.

According to the [official introduction](https://www.kimi.com/resources/kimi-k2-7-code), this is because K2.7's inference capability has been "slimmed down," reducing token consumption by an average of 30% compared to the previous version. Kimi's advantage has always been cost-effectiveness, and this update reinforces that advantage — very promising.
