# Is MiniMax "Disrupting" Itself? M2.7's Self-Evolution

## I. Introduction

Yesterday, [MiniMax M2.7](https://minimaxi.com/models/text/m27) was released.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031807.webp)

I was stunned — the previous version M2.5 was released just a month ago, with the Spring Festival in between, and there's already a new version so quickly.

This time, the official tagline is "Unlocking AI Self-Evolution."

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031808.webp)

What does this mean? Did the model evolve a new version by itself, hence the rapid upgrade?

## II. Model Self-Evolution

I read the [release notes](https://mp.weixin.qq.com/s/Xfsq8YDP7xkOLzbh1HwdjA), and it's indeed "**the model iterating on itself**."

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031809.webp)

According to the introduction, after receiving user input, the model automatically generates an Agent Harness. This is different from before.

I looked it up — this English term seems to mean a "test framework," referring to a set of constraints.

Based on these constraints, the model **autonomously evaluates its own performance and, based on the evaluation, enters the next iteration until it achieves the optimal result**, thus achieving "self-iteration."

> "During operation, after each iteration, the Agent forms a short-term memory md file, while also providing self-feedback on the current result, offering potential optimization directions for the next round. The next round performs self-optimization based on all historical memory and self-feedback chains."

For software projects, the model's behavior is "optimize a specific point → self-evaluate the optimization → if unsatisfactory, modify code → run evaluation → compare results → decide to keep or revert." This iteration loop can exceed 100 rounds.

The official statement says that models trained with this mechanism perform exceptionally well.

> "In the MLE Lite 22 high-difficulty competitions, it achieved 9 gold, 5 silver, and 1 bronze, with a medal rate of 66.6%, second only to Opus-4.6 (75.7%) and GPT-5.4 (71.2%), tied with Gemini-3.1."

On the industry's most important SWE Bench Pro, its score is second only to foreign flagship models like Sonnet 4.6, Opus 4.6, and GPT 5.4.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031810.webp)

## III. Programming Capability

After reading the official introduction, I proceeded to test its actual programming capability.

I used my own [test suite](https://github.com/ruanyf/ai-test-case). This suite was also used to [test MiniMax M2.5](https://mp.weixin.qq.com/s/mAwlBB1QPG9s4q3YJ45KRQ) previously, allowing for comparison.

I'll cut to the chase: programming capability has improved over the previous version, but the improvement isn't dramatic — evident in refined details.

## IV. Skill Capability

The official announcement didn't dwell much on programming capability. Among the highlights mentioned, Skill capability improvement was more prominent.

> "Calling various skills and tools while maintaining stable instruction following in long-range interactions. M2.7 has greatly improved in these areas... maintaining 97% skill adherence rate."

They also released an [official Skill repository](https://github.com/MiniMax-AI/skills). As far as I know, this is the first domestic AI company to do so.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031901.webp)

Since it was just released, there aren't many Skills yet — only 6.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031902.webp)

The provided capabilities include frontend, full-stack, iOS, Android, and 3D rendering.

For installing official Skills, refer to the [repository documentation](https://github.com/MiniMax-AI/skills/blob/main/README_zh.md) and choose according to your Coding Agent. Mine is Claude Code.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031903.webp)

I ran a small test, first testing the result without using a Skill.

> Generate a webpage where users can load an SQLite database file and display the database's entity-relationship diagram. Generate without using Skills.

The page result (without Skill):

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031904.webp)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031905.webp)

Second time with the same prompt, but requiring Skill use:

> Call the frontend-dev skill to generate a webpage where users can load an SQLite database file and display the database's entity-relationship diagram.

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031907.webp)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031906.webp)

As you can see, after calling the skill, the page is more beautiful with better detail handling.

More importantly, without the Skill, the generated application had a backend — requiring a Python backend service to read the database. After using the frontend Skill, it became a purely static page with no backend — the SQLite database is handled entirely on the frontend by WebAssembly scripts.

After using it, I feel MiniMax M2.7 is a clear improvement over the previous version, supporting more scenarios for various use cases.

**Programming and text processing are its strengths**, especially for complex problems.

If it has truly achieved "self-iteration," we might not be far from fully automatic "self-evolution." I'm curious what the next version will be like and how long it will take.
