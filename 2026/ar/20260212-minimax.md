# MiniMax M2.5 Hands-on: Going Head-to-Head with Opus 4.6 and GPT 5.3

## I. Introduction

Yesterday, I had just relaxed, ready for the holiday, when I turned around and saw that MiniMax and DeepSeek had both updated almost simultaneously.

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026021233.webp)

MiniMax released its [new flagship model M2.5](https://www.minimaxi.com/news/minimax-m25), while DeepSeek had a minor version parameter update. Was this a quiet competition, or were they all rushing to release new models before the Spring Festival? I had no choice but to sit down and examine what improvements the new version brings.

MiniMax's M2 series is one of China's top programming models. For the past while, I've been using its M2.1 model daily, so this upgrade was a must-follow.

I asked MiniMax colleagues for a beta account, tested its programming capabilities, and compared it with the latest flagship foreign models — Claude Opus 4.6 and GPT-5.3-Codex — to see if there's a gap and whether domestic models can replace imported ones. I wrote this review before the holiday break.

## II. M2.5 Introduction

According to the official announcement, M2.5 has been enhanced in several areas.

(1) **Coding & Agentic Performance**: **Benchmarked against Opus 4.6**, with a SWE-verified score of 80.2, matching Opus 4.6 (see below).

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026021232.webp)

(2) **Deeply Optimized Agent Architecture**: Possesses **strong task planning and long-chain execution capabilities**, compatible with various domestic and international agents.

(3) **Fast Inference Speed**: Achieves 100 TPS (tokens per second), nearly twice that of Opus.

(4) **Suitable for Private Deployment**: Only 10B activated parameters, making it the smallest flagship model. It also has advantages in memory usage and inference efficiency.

## VI. PHP to JS Conversion

The third test was converting a PHP Laravel application to JavaScript Next.js.

MiniMax M2.5 handled the conversion quickly and smoothly. The resulting code compiled and ran correctly.

Opus 4.6 also converted successfully, though it took 20 minutes. GPT-5.3 was similar to the others.

The generated page was a weather query application, looking identical to the PHP original with no style changes requested.

In this round, all three models performed well, but MiniMax M2.5 had the shortest generation time, so I'd rank it first, followed by GPT-5.3, then Opus 4.6.

## VII. Summary

After these tests, I believe MiniMax M2.5 has narrowed the gap with top-tier foreign models in terms of performance. It can keep pace with Opus 4.6 and GPT-5.3 in everyday programming and even surpasses GPT 5.3 in certain aspects. Its highlights are fast inference, strong coding capabilities, and suitability for private deployment.

For users seeking a cost-effective, high-quality programming model, MiniMax M2.5 is worth considering.
