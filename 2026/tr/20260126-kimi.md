# Kimi

Currently, large models are divided into two types: single-modal and multimodal. Major companies are now researching a third type: "omnimodal models."

"Modality" refers to the type of data. A large model that can only process a single type of data — for example, only text — is called single-modal.

If it can process two types of data — for instance, both text and image input — then it's a multimodal model.

Clearly, **an omnimodal model can handle all data types.**

The human brain can accept various types of data for unified thinking. So many scientists believe that future "Artificial General Intelligence" (AGI) should be an omnimodal model: regardless of the content type, it can be submitted for analysis and processing, and its output can also be of various types.

This is not just about writing code — it's "seeing an image and writing an app."

- **Use cases:** Quickly creating landing pages, converting design drafts to code, creating cool interactive animations.

**2. Agent Swarm: One Person Army — "Swarm Intelligence"**

Solving complex problems is no longer about a single AI fighting alone, but a group of AIs collaborating.

- **High concurrency:** In Agent mode, Kimi can instantly decompose tasks and simultaneously dispatch multiple "avatars" to work together. It can independently complete up to 1,500 steps in one go (unlimited avatars).

- **Batch processing powerhouse:**
  - Batch search: Research 100 listed companies at once.

- **Multi-perspective debate:** You can ask Kimi to simulate different roles (e.g., pro, con, judge), debate with itself, and output an airtight business plan.

**3. Office Agent: Expert-Level "Office Partner"**

Kimi's office capabilities have been upgraded beyond simple text processing to expert-level Office assistance.

- **Professional output:** Deeply optimized for PPT, Word, and Excel. Deliverables have professional aesthetics and structure.

- **Deep parsing:** Not just reading documents, but also understanding charts and complex layouts within documents using visual capabilities.

**4. Developer's Delight: Open-Source Claude Code — Kimi Code**

Kimi Code is Kimi's self-developed Terminal-based Coding Agent. It can perform CRUD operations on code locally. Within a local project, it can read files, understand structure, then automatically generate/modify code, run tests or commands, and explain changes.

- **Open source:** Transparent and auditable, safe and trustworthy.

- **Supports all existing features:** Agent.md/Skill auto-discovery, MCP model natural language installation — easy migration for developers.
- **High benchmark scores:** Two benchmarks — SWE Bench Verified / Kimi Internal Code Bench.

# Towards Omnimodal: A First Look at Kimi K2.5 Visual Coding

## I. What is Omnimodal?

Introducing the concept of omnimodal, leading to Kimi K2.5.

Kimi K2.5 is an all-around unified model — "all in one." You can use it for various tasks.

It can process text and also has vision — meaning it can handle images and videos. Once audio capability is added, it becomes an omnimodal model. It is the latest achievement of Chinese AI companies exploring "omnimodal."

## II. The Kimi Model Series

Looking back at the wave sparked by the Kimi K2 model, including evaluations from foreign researchers at the time, highlighting that this series of models deserves attention.

K2.5 is an upgrade to K2, adding several important capabilities and moving toward all-around development.

## III. Kimi K2.5 Capabilities

Kimi K2.5's all-around nature means a single model can handle various tasks:

(1) Can converse and answer various questions.
(2) Can process Office files — officially claimed to "expert-level" deeply understand and generate PPT, Word, and Excel files.
(3) Can program — launched Kimi Code, comparable to Claude Code.
(4) Swarm and long operations. It decomposes problems internally and distributes them to a group of AIs for concurrent processing, like a swarm — e.g., batch search, batch generation, and multi-perspective debate (multiple AIs simulating different roles). At the same time, it supports long-range operations, claiming to independently complete up to 1,500 steps in one go.

## IV. Visual Coding Capability
