## Model Introduction

### Seed 2.0 General Model

Seed 2.0 model capability improvements are as follows:

- **Stronger Multimodal Understanding:** Excels in multimodal perception, high-precision text extraction, chart understanding, spatial understanding, motion understanding, visual knowledge and reasoning, and long video understanding.

- **Enterprise-Grade Agent Capabilities:** The model better supports understanding and application of Skills. Function Call, multi-turn instruction following, search and tool invocation capabilities are significantly enhanced. Format output is more stable. Flexible context management is supported. Better support for enterprise-level complex, long-range tasks. Performs excellently in enterprise scenarios such as data analysis and customer service Agent.

- **Stronger Reasoning and Code Capabilities:** The model has stronger reasoning ability, supports adjustable thinking length, and Token efficiency is greatly improved across all thinking lengths. The model's coding ability, especially in frontend development, has seen significant improvement.
