# Tech Enthusiast Weekly (Issue 440)

## Tools

1. [perfect-freehand](https://github.com/steveruizok/perfect-freehand)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025082010.webp)

A web app that supports freehand drawing.

1. [OverType](https://github.com/panphora/overtype)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081810.webp)

A JS library for embedding a WYSIWYG Markdown editor in a web page.

1. [ClipCascade](https://github.com/Sathvik-Rao/ClipCascade)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025082007.webp)

An open-source app for sharing the clipboard between devices. You can use the official server or host your own, and clients are available for various desktop and mobile systems.

1. [Bru](https://bru.works/)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026101419.webp)

An Android app that connects your phone and computer, letting you send and receive phone text messages in a desktop browser. When a message arrives, a notification appears on the desktop. The desktop side can also read and write the phone's clipboard and send files to the phone.

1. [LumineCapture](https://github.com/Netflate/LumineCapture)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026101503.webp)

A brand-new screenshot tool for the Wayland desktop environment on Linux.

1. [Fleeting](https://iminafleeting.com/)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026101417.webp)

A very creative website that pretends you are attending an online meeting. You can also use it as background audio and work while listening to the meeting.

1. [EmbedPDF](https://github.com/embedpdf/embed-pdf-viewer)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081813.webp)

A JS library for embedding a PDF reader in a web page.

1. [ArchiveBox](http://archivebox.io/)

![](https://cdn.beekka.com/blogimg/asset/202410/bg2024101703.webp)

A web page capture tool that creates local backups of pages in the Internet Archive format, with its own web front end.

1. [snitch](https://github.com/karol-broda/snitch)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010314.webp)

A command-line tool that shows which program is using each port, in a user-friendly format in the terminal.

1. [Convert HTML to PNG](https://html2png.dev/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010401.webp)

This site renders HTML code into a downloadable PNG image.

1. [SMTP Tunnel Proxy](https://github.com/x011/smtp-tunnel-proxy)

A network tunnel tool that disguises TCP traffic as email traffic, with both server and client.

1. [Diffs](https://diffs.com/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010715.webp)

A JS library for generating various diff views of code.

1. [Porterminal](https://github.com/lyehe/porterminal)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010315.webp)

A cross-platform network tool for sharing a terminal. After installation, the PC terminal displays a QR code; scanning it with your phone lets you access that PC terminal in a mobile browser, and the two do not need to be on the same local network.

1. [fp-pack](https://github.com/superlucky84/fp-pack)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010402.webp)

A functional programming library for JS/TS, offering various utility functions.

1. [DoNotNotify](https://donotnotify.com/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010601.webp)

An Android app that lets you set text-matching rules to filter pop-up notifications on your phone.

1. [Duplicati](https://github.com/duplicati/duplicati/blob/master/README.zh-CN.md)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025051011.webp)

A cross-platform desktop app with a graphical interface for backing up local files to various cloud storage services. See the [introductory article](https://www.xda-developers.com/finally-started-using-duplicati-should-have-sooner/).
