# Tech Enthusiast Weekly (Issue 410)

## Tools

1. [Dark mode PDFs](https://veil.simoneamico.com/)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026032702.webp)

A very interesting little tool website that inverts the colors of uploaded PDF files, turning white background with black text into black background with white text.

1. [Email.md](https://www.emailmd.dev/templates)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026032801.webp)

This website provides email templates. Users just need to fill in Markdown format, and it will generate a formatted email.

10. [Minimalytics](https://github.com/nafey/minimalytics)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032101.webp)

A statistics server that records and monitors various events, based on Go language and SQLite database, with a built-in web interface.

1. [Liberapay](https://zh-hans.liberapay.com/)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032205.webp)

A donation-collecting SaaS service that helps you put a 'Donate' button on your webpage, supporting Chinese Yuan.

1. [Sōzu](https://github.com/sozu-proxy/sozu)

![](https://cdn.beekka.com/blogimg/asset/202511/bg2025111803.webp)

A lightweight reverse proxy server written in Rust, configuration without reloading, with built-in SSL support.

10. [Turso](https://github.com/tursodatabase/turso)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070402.webp)

This project rewrites the SQLite database using Rust, aiming to be fully compatible with the SQLite API, and supports concurrent writes and asynchronous operations.

1. [Apprise](https://github.com/caronc/apprise)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070401.webp)

An open-source notification service that can send messages to mainstream communication software abroad. See [introduction article](https://www.xda-developers.com/reasons-use-apprise-instead-of-ntfy-gotify/).

1. [Djot](https://djot.net/)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070713.webp)

Djot is a simplified version of Markdown, simplifying many complex cases (like nested syntax), making parsing speed significantly faster. Its parser [Jotdown](https://github.com/hellux/jotdown) is one-tenth the speed of the Markdown parser [lowdown](http://kristaps.bsd.lv/lowdown/). If your Markdown files are simple, you can use it.

1. [SSLCheck](https://github.com/i04n/sslcheck)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070315.webp)

A simple Python script to check if a website's SSL certificate is valid from the command line.

1. [Shaarli](https://github.com/shaarli/Shaarli)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032206.webp)

A minimal personal bookmark application, developed in PHP.

## Images

1. [London's Smallest Sculptures](https://lookup.london/londons-smallest-public-sculptures/)

London has several small public sculptures that are quite unexpected.

On the top of the ground floor of a commercial street, there is a sculpture of two mice stealing cheese.

![](https://cdn.beekka.com/blogimg/asset/202605/bg2026051704.webp)

It is said to commemorate a tragic event.

![](https://cdn.beekka.com/blogimg/asset/202605/bg2026051705.webp)

In the 19th century, two workers got into a violent fight here over a missing piece of cheese, which led to a fatal incident. It was later discovered that the cheese had been stolen by mice.

There is also a "Mouse House" sculpture in London.

![](https://cdn.beekka.com/blogimg/asset/202605/bg2026051706.webp)

The shop owner noticed that a street number was missing, so he created this sculpture and gave the missing number to this mouse house.
