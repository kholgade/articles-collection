# Tech Enthusiast Weekly (Issue 434)

## Tools

1. [Entropy](https://github.com/EwenQuim/entropy)

![](https://cdn.beekka.com/blogimg/asset/202406/bg2024060501.webp)

A command-line tool that scans a codebase and finds lines with high entropy values, which typically indicate hardcoded passwords.

1. [Bruno](https://www.usebruno.com/)

![](https://cdn.beekka.com/blogimg/asset/202310/bg2023100208.webp)

An open-source IDE similar to Postman for developing and debugging APIs. A similar tool is [HTTPie Desktop](https://github.com/httpie/desktop).

1. [Pragtical](https://pragtical.dev/)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025062103.webp)

A lightweight cross-platform code editor with many built-in features and easy extensibility.

1. [Harper](https://writewithharper.com/)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025062104.webp)

An open-source editor/browser plugin for correcting English grammar errors, similar to the paid Grammarly.

1. [MSI Viewer pymsi](https://pymsi.readthedocs.io/en/latest/msi_viewer.html)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025062105.webp)

An online tool that lets you inspect the contents of Microsoft installer (.msi) files.

1. [Fuse.js](https://www.fusejs.io/)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120701.webp)

A lightweight fuzzy-search library usable on both frontend and backend. Here is a [tutorial](https://konfigthis.com/blog/how-to-implement-free-fast-local-search-with-fuse-js-with-next-js-ssr) on using it with Next.js.

1. [tshark](https://termshark.io/)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120706.webp)

A terminal-based packet analyzer similar to Wireshark for inspecting local network traffic.

1. [Wify](https://github.com/yilinjuang/wify)

An open-source React Native app that scans WiFi credentials posted on walls (e.g., in hotels or cafes), uses OCR to read them, and connects automatically.

1. [Qustar](https://github.com/tilyupo/qustar)

A creative JS database query library that uses array-method-style syntax to perform SQL queries.

1. [typr](https://github.com/Sakura-sx/typr)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025062701.webp)

A terminal-based typing practice program written in Python that tracks typing speed and accuracy.

## Resources

1. [Best Methods for OCR](https://news.ycombinator.com/item?id=43048698)

A Hacker News discussion thread on the best current methods for optical character recognition (OCR), with most respondents recommending AI-based approaches.

1. [3D Tenochtitlan](https://tenochtitlan.thomaskole.nl/index.html)

![](https://cdn.beekka.com/blogimg/asset/202502/bg2025021816.webp)

The Aztec capital Tenochtitlan was once one of the world's largest cities, with 5 million residents, located where Mexico City stands today. This project provides a 3D reconstruction.

1. [2D Game Development: From Zero To Hero](https://github.com/2DGD-F0TH/2DGD_F0TH)

![](https://cdn.beekka.com/blogimg/asset/202501/bg2025010804.webp)

A free open-source English e-book on 2D game development, available in multiple language versions (pseudocode, Python, C++, JavaScript, Lua).

1. [Python Training](https://github.com/jpmorganchase/python-training)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024083002.webp)

JP Morgan's Python training course for analysts and traders, published on GitHub.

1. [TinyCompiler: A Simple Compiler Tutorial](https://ssloy.github.io/tinycompiler/)

![](https://cdn.beekka.com/blogimg/asset/202502/bg2025022201.webp)

A series of articles teaching you to write a simple compiler in 500 lines of Python.

1. [Web Browser Engineering](https://browser.engineering/index.html)

![](https://cdn.beekka.com/blogimg/asset/202410/bg2024101603.webp)

A freely readable English e-book explaining how browsers work, using Python scripts as examples to implement a simple browser.
