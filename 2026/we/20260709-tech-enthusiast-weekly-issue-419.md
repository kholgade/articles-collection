# Tech Enthusiast Weekly (Issue 419)

## Tools

3、[dnsglobe](https://github.com/514-labs/dnsglobe)

![](https://cdn.beekka.com/blogimg/asset/202607/bg2026070702.webp)

A command-line tool that tests the speed of 34 public DNS servers worldwide and finds the fastest one for you.

1、[kan.ban](https://github.com/kanbn/kan)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025060312.webp)

An open-source kanban application based on JS, an alternative to Trello.

1、[Grafito](https://github.com/ralsina/grafito)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025060313.webp)

View local Systemd logs (journalctl) in real-time via a web interface. See [introductory article](https://linuxiac.com/grafito-systemd-journal-log-viewer-with-a-beautiful-web-ui/).

4、[qmd](https://github.com/tobi/qmd)

A command-line tool that builds a vector index for text files, enabling local semantic search.

1、[Fence](https://github.com/Use-Tusk/fence)

A sandbox tool that blocks network access and file system operations by default, suitable for running external code.

1、[difi](https://github.com/oug-t/difi)

A command-line tool to view the diff between the current branch and the main branch.

1、[DPaint.js](https://github.com/steffest/DPaint-js)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026012901.webp)

A browser-based open-source image editor.

1、[WireGuard Easy](https://github.com/wg-easy/wg-easy)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025060108.webp)

Claims to be the simplest way to install and manage WireGuard, with a built-in Web UI, suitable for connecting to an internal network from outside.

Similar tools include [Wiredoor](https://github.com/wiredoor/wiredoor) and [NetBird](https://github.com/netbirdio/netbird).

1、[Redirector](https://github.com/einaregilsson/Redirector)

An open-source browser extension that can rewrite URLs, redirecting URLs that match specified rules to other URLs.

1、[Berb](https://github.com/nihaocami/berb)

![](https://cdn.beekka.com/blogimg/asset/202506/bg2025060202.webp)

An open-source peer-to-peer (P2P) file sharing website.

A similar tool is [PinSend](https://pinsend.app/).
