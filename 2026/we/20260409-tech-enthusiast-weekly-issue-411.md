# Tech Enthusiast Weekly (Issue 411)

## Tools

1. [Kahuna](https://github.com/hummingme/kahuna)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025040901.webp)

Open-source browser extension for managing the browser's built-in IndexedDB database. It also automatically prompts if the current webpage uses IndexedDB.

1. [Stalwart](https://github.com/stalwartlabs/mail-server)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032902.webp)

Open-source all-in-one full-featured mail server.

1. [Mint](https://mint.photo/)

![](https://cdn.beekka.com/blogimg/asset/202511/bg2025112402.webp)

Web-based image editor, [open-source code](https://github.com/mosaiq-software/mint).

1. [Dropflow](https://github.com/chearon/dropflow)

An independently implemented CSS engine that renders CSS code without a browser, suitable for backend rendering of canvas to generate images.

1. [libsearch](https://github.com/thesephist/libsearch)

Lightweight JS search library that sorts search results by TF-IDF.

1. [@smoores/epub](https://www.npmjs.com/package/@smoores/epub)

Node.js library for manipulating Epub e-book files.

1. [BunkerWeb](https://github.com/bunkerity/bunkerweb)

![](https://cdn.beekka.com/blogimg/asset/202412/bg2024123106.webp)

Open-source Web Application Firewall (WAF) that filters malicious requests to websites.

1. [DOMPurify](https://github.com/cure53/DOMPurify)

A JS module for sanitizing HTML code to prevent XSS attacks.

1. [Popply](https://github.com/JhojanGgarcia/PopplyLibrary)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070403.webp)

A CSS library for tooltips, collecting CSS snippets with various animation effects.

1. [Fast Music Remover](https://github.com/omeryusufyagci/fast-music-remover)

A tool for removing background music and noise, useful for cleaning up interview audio.

## Resources

1.  [Email is Easy](https://e-mail.wtf/)

    ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081812.webp)

    An online quiz that tests how much you know about email formats. There are 20 email addresses, and you need to determine which ones are valid.

2.  [Periodic Table](https://periodictable.com/)

    ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081811.webp)

    This website displays images of each chemical element according to its position on the periodic table. Clicking on an element shows its introduction.

3.  [HTML Canvas Deep Dive](https://joshondesign.com/p/books/canvasdeepdive/title.html)

    ![](https://cdn.beekka.com/blogimg/asset/202406/bg2024061402.webp)

    A free English e-book that provides a detailed introduction to using Canvas to generate graphics on web pages.

4.  [Bouncy Ball](https://sparkbox.github.io/bouncy-ball/)

    ![](https://cdn.beekka.com/blogimg/asset/202406/bg2024061511.webp)

    This website collects various methods for displaying a bouncing ball animation on a web page.
