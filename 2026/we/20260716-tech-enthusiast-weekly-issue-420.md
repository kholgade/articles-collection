# Tech Enthusiast Weekly (Issue 432)

## Tools

1、[sgrep](https://github.com/arunsupe/semantic-grep)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024072803.webp)

A grep alternative that uses word embedding for semantic search, searching for keywords within files. The image above shows a search for "death" returning results that include "killing".

1、[Netdata](https://github.com/netdata/netdata)

![](https://cdn.beekka.com/blogimg/asset/202509/bg2025092707.webp)

An open-source dashboard that displays the status of all servers and services in one place.

1、[FlowVision](https://github.com/netdcy/FlowVision)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082008.webp)

A waterfall-style image browser for macOS.

1、[13ft](https://github.com/wasi-master/13ft)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082009.webp)

An open-source website that can scrape some paywalled URLs, requires self-hosting.

1、[netboot.xyz](https://netboot.xyz/)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082010.webp)

An operating system boot disk that provides installation options for Windows, Linux, and BSD in one place.

1、[Srcbook](https://github.com/srcbookdev/srcbook)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082013.webp)

A web-based interactive notebook similar to Jupyter Notebook, but for TypeScript and JavaScript.

2、[OpenSlack](https://github.com/BilalG1/openslack)

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026022301.webp)

An open-source implementation of Slack, a real-time messaging team tool, featuring channels, topics, direct messages, group discussions, search, and file sharing.

1、[Mos](https://github.com/ich777/mos-releases)

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026021612.webp)

A container management system for home use, capable of managing Docker containers, LXC containers, and Qemu virtual machines.

1、[devPush](https://github.com/hunvreus/devpush)

![](https://cdn.beekka.com/blogimg/asset/202510/bg2025100805.webp)

An automatic code fetching and running platform that allows you to set up your own CI/CD environment, as an open-source alternative to Vercel/Render/Netlify.

1、[Resterm](https://github.com/unkn0wn-root/resterm)

![](https://cdn.beekka.com/blogimg/asset/202510/bg2025100201.webp)

A REST API client in the terminal, supporting HTTP, GraphQL, and gRPC protocols.
