# Tech Enthusiast Weekly (Issue 418)

## Tools

1. [Sniffnet](https://github.com/GyulyVGC/sniffnet)

![](https://cdn.beekka.com/blogimg/asset/202502/bg2025020405.webp)

An open-source application for monitoring local internet traffic.

1. [Portr](https://github.com/amalshaji/portr)

![](https://cdn.beekka.com/blogimg/asset/202404/bg2024042201.webp)

An open-source tool that exposes internal network services to the public via tunnels, touted as an alternative to ngrok.

1. [dut](https://codeberg.org/201984/dut)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024071106.webp)

A command-line tool that calculates the space occupied by directories on Linux, similar to ncdu.

1. [React Photo Studio](https://github.com/chase-manning/react-photo-studio)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025052603.webp)

A web-based photo editing application.

10. [Cally](https://wicky.nillia.ms/cally/)

![](https://cdn.beekka.com/blogimg/asset/202404/bg2024041411.webp)

A web component for generating calendars.

1. [bearclaw](https://github.com/donuts-are-good/bearclaw)

![](https://cdn.beekka.com/blogimg/asset/202311/bg2023110604.webp)

A very simple static site generator written in Go, very fast.

1. [Cicada](https://github.com/Cicada-Software/cicada)

![](https://cdn.beekka.com/blogimg/asset/202311/bg2023110701.webp)

An open-source alternative to GitHub Actions and GitLab CI, can be self-hosted or use their cloud service.

1. [OCR4all](https://www.ocr4all.org/)

![](https://cdn.beekka.com/blogimg/asset/202502/bg2025021508.webp)

An OCR Docker application with a web UI.

1. [Cloudflare NoIP](https://github.com/devrim/cloudflare-noip)

A dynamic DNS tool that uses Cloudflare Workers to periodically update DNS records for internal services.

2. [RaspAP](https://raspap.com/)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025053002.webp)

This tool can turn a Debian-based device into a router. For example, turn a Raspberry Pi into a router, see the [introductory article](https://www.xda-developers.com/turn-raspberry-pi-into-travel-router/).

## Resources

1. [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/) (English)

![](https://cdn.beekka.com/blogimg/asset/202512/bg2025120404.webp)

Free to read: 'Python Data Science Handbook', which introduces beginners to some basic Python tools for data processing (e.g., NumPy, Pandas), published in 2016.

1. [Learn CSS Layout](https://book.mixu.net/css/) (English)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032901.webp)

A free English e-book introducing CSS layout, including box model and Flexbox.

1. [rovers.land](https://www.rovers.land/)

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026041813.webp)

This website organizes every photo sent back to Earth by the Curiosity rover since 2013, arranged by route, creating a 'street view' of Mars.

1. [Silk Road Interactive Map](https://www.intofarlands.com/silk-roads-map)

![](https://cdn.beekka.com/blogimg/asset/202604/bg2026041814.webp)

This website provides an interactive map of the Silk Road, allowing you to explore each route on the map.
