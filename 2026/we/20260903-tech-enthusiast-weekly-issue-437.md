# Tech Enthusiast Weekly (Issue 437)

## Tools

1. [SSLCheck](https://github.com/i04n/sslcheck)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070315.webp)

A simple Python script for checking the validity of a website's SSL certificate from the command line.

1. [Shaarli](https://github.com/shaarli/Shaarli)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032206.webp)

A minimalist personal bookmarking application written in PHP.

1. [binvis.io](https://binvis.io)

![](https://cdn.beekka.com/blogimg/asset/202608/bg2026082901.webp)

Upload any binary file to see a visual byte-map of its contents.

1. [Kahuna](https://github.com/hummingme/kahuna)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025040901.webp)

An open-source browser plugin for managing the browser's built-in IndexedDB database, with automatic detection when a page uses IndexedDB.

1. [Stalwart](https://github.com/stalwartlabs/mail-server)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032902.webp)

An open-source all-in-one full-featured mail server.

1. [Mint](https://mint.photo/)

![](https://cdn.beekka.com/blogimg/asset/202511/bg2025112402.webp)

A web-based image editor with [open-source code](https://github.com/mosaiq-software/mint).

1. [Dropflow](https://github.com/chearon/dropflow)

An independently implemented CSS engine that renders CSS without a browser, suitable for server-side rendering of canvas images.

1. [libsearch](https://github.com/thesephist/libsearch)

A lightweight JS search library that ranks results using TF-IDF.

1. [@smoores/epub](https://www.npmjs.com/package/@smoores/epub)

A Node.js library for working with EPUB e-book files.

1. [BunkerWeb](https://github.com/bunkerity/bunkerweb)

![](https://cdn.beekka.com/blogimg/asset/202412/bg2024123106.webp)

An open-source Web Application Firewall (WAF) for filtering malicious requests.

## Resources

1. [Postgres by Example](https://github.com/boringcollege/postgres-by-example)

A tutorial for learning PostgreSQL through SQL examples. Each lesson is brief (a few minutes) and comes with a `.sql` file.

1. [Docker Made Easy](https://learn-how-docker-works.vercel.app/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026011401.webp)

An open-source interactive Docker beginner tutorial in web form.

1. [Bash Screensavers](https://github.com/attogram/bash-screensavers)

![](https://cdn.beekka.com/blogimg/asset/202510/bg2025103004.webp)

A collection of more than a dozen screensaver effects that run in a Bash terminal.

1. [100 Science Books That Shaped a Century](https://web.mnstate.edu/schwartz/centurylist2.html)

![](https://cdn.beekka.com/blogimg/asset/202502/bg2025020501.webp)

The 100 best science books selected by American Scientist magazine in 1999.
