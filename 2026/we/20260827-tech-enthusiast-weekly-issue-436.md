# Tech Enthusiast Weekly (Issue 436)

## Tools

1. [Wave Terminal](https://www.waveterm.dev/)

![](https://cdn.beekka.com/blogimg/asset/202403/bg2024031202.webp)

A modern, open-source terminal emulator supporting macOS and Linux.

1. [Ayllu](https://ayllu-forge.org/)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023121101.webp)

A web UI for Git repositories, for self-hosting Git repos.

1. [Don't Fuck With Paste](https://github.com/aaronraimist/DontFuckWithPaste)

![](https://cdn.beekka.com/blogimg/asset/202403/bg2024031006.webp)

An open-source browser plugin that re-enables copy-paste in input fields that have it blocked.

1. [Timelock](https://timelock.dev/)

![](https://cdn.beekka.com/blogimg/asset/202403/bg2024031201.webp)

An open-source online tool for encrypting messages that can only be decrypted after a specified time.

1. [Liberapay](https://zh-hans.liberapay.com/)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025032205.webp)

A SaaS service for accepting donations, adding a "Donate" button to your web page, with support for CNY.

1. [Sōzu](https://github.com/sozu-proxy/sozu)

![](https://cdn.beekka.com/blogimg/asset/202511/bg2025111803.webp)

A lightweight reverse proxy server written in Rust, with no-reload configuration changes and built-in SSL support.

1. [Turso](https://github.com/tursodatabase/turso)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070402.webp)

A Rust rewrite of SQLite targeting full API compatibility while adding concurrent writes and async operations.

1. [Apprise](https://github.com/caronc/apprise)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070401.webp)

An open-source notification service that can send messages to mainstream communication platforms. See the [introduction article](https://www.xda-developers.com/reasons-use-apprise-instead-of-ntfy-gotify/).

1. [Djot](https://djot.net/)

![](https://cdn.beekka.com/blogimg/asset/202507/bg2025070713.webp)

A simplified version of Markdown that removes complex edge cases (e.g., nested syntax), greatly speeding up parsing. Its parser [Jotdown](https://github.com/hellux/jotdown) is ten times faster than the Markdown parser [lowdown](http://kristaps.bsd.lv/lowdown/).

1. [Fast Music Remover](https://github.com/omeryusufyagci/fast-music-remover)

A tool for removing background music and noise, useful for cleaning up interview recordings.

## Resources

1. [Bouncy Ball](https://sparkbox.github.io/bouncy-ball/)

![](https://cdn.beekka.com/blogimg/asset/202406/bg2024061511.webp)

A site collecting various approaches to implementing a bouncing ball web animation.

1. [learn-c.org](https://www.learn-c.org/)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042702.webp)

An interactive English tutorial for C beginners, with runnable code examples in each chapter. There is also an [introductory tutorial](https://helderman.github.io/htpataic/htpataic01.html) that teaches C by building a text adventure game.

1. [Effective Rust](https://www.lurklurk.org/effective-rust/title-page.html)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025030613.webp)

A freely readable English e-book covering 35 ways to improve your Rust code.

1. [OAuth2 Explained](https://www.romaglushko.com/blog/whats-aouth2/)

![](https://cdn.beekka.com/blogimg/asset/202501/bg2025012907.webp)

A long-form article explaining the OAuth2 authentication protocol in detail, from its design philosophy to practical applications.
