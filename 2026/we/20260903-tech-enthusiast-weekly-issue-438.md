# Tech Enthusiast Weekly (Issue 438)

## Tools

1. [DOMPurify](https://github.com/cure53/DOMPurify)

A JS module for sanitizing HTML to prevent XSS attacks.

1. [Popply](https://github.com/JhojanGgarcia/PopplyLibrary)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070403.webp)

A CSS library for tooltips, collecting CSS snippets with various animation effects.

1. [Posting](https://github.com/darrenburns/posting)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070711.webp)

A terminal-based HTTP client for testing HTTP requests, similar to Postman.

1. [impala](https://github.com/pythops/impala)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070810.webp)

A WiFi manager for Linux terminals.

1. [Tegon](https://github.com/tegonhq/tegon)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070905.webp)

An open-source task management system, an alternative to Jira.

1. [Rybbit](https://github.com/rybbit-io/rybbit)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025050804.webp)

An open-source website visitor analytics tool, an alternative to Google Analytics.

1. [VeraCrypt](https://github.com/veracrypt/VeraCrypt)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025050408.webp)

Powerful data encryption software that can encrypt entire disks, supporting all major desktop systems. See the [introduction article](https://www.xda-developers.com/started-using-tool-encrypt-files/).

1. [CodeCafé](https://github.com/mrktsm/codecafe)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025050601.webp)

An open-source browser-based web code editor supporting real-time collaborative programming.

1. [gotui](https://github.com/metaspartan/gotui)

![](https://cdn.beekka.com/blogimg/asset/202512/bg2025121201.webp)

A Go library for building terminal user interfaces with various widgets.
