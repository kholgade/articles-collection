# Tech Enthusiast Weekly (Issue 439)

## Tools

1. [Rift](https://acsandmann.github.io/rift-docs/)

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026093012.webp)

A tiling window manager for macOS that can move, resize, and rearrange windows.

1. [photoc](https://github.com/ahmetomerv/photoc)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026100803.webp)

A command-line tool for processing photos. It can automatically rename photos based on when they were taken and sort them into matching directories.

1. [Quarkdown](https://github.com/iamgio/quarkdown)

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026092003.webp)

A new typesetting tool that uses a Markdown-derived syntax to produce high-quality PDF print documents. It can also convert to HTML web pages, and claims to be easier to use than [Typst](https://typst.app/).

1. [passbolt](https://www.passbolt.com/)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042902.webp)

An open-source password manager. See the [introductory article](https://www.xda-developers.com/reasons-why-use-passbolt-manage-passwords/).

1. [Sidequest.js](https://docs.sidequestjs.com/)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081111.webp)

A queue/job library for Node.js.

1. [Nerdlog](https://github.com/dimonomid/nerdlog)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042904.webp)

A tool for quickly viewing remote server logs in the terminal.

1. [EasyMDE](https://github.com/Ionaru/easy-markdown-editor)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025043003.webp)

A Markdown editor that can be embedded in web pages. See the [introductory article](https://avohq.io/blog/markdown-image-uploads-easy-mde-rails).

1. [Pangolin](https://github.com/fosrl/pangolin)

![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042905.webp)

A reverse tunnel tool that lets you reach internal servers without opening any ports. See the [introductory article](https://www.xda-developers.com/alternative-to-tailscale-or-nginx-remote-access-home-lab/).

1. [PrivTracker](https://privtracker.com/)

![](https://cdn.beekka.com/blogimg/asset/202501/bg2025011803.webp)

A private tracker service for BitTorrent downloads, letting you run private torrents. [The code is open source](https://github.com/meehow/privtracker).

1. [lazy-brush](https://github.com/dulnan/lazy-brush)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025082009.webp)

A JS library that produces smooth curves from a mouse, finger, or other input.

## Resources

1. [Museum of Ages: Da Vinci](https://museumofages.org/w/vinci?film=job&lang=en#via=direct)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026101420.webp)

A virtual 3D museum exhibiting Leonardo da Vinci's works, which you can explore freely.

1. [YouTube Webcam Map](https://worldwatcher.live/)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026100902.webp)

This site places live YouTube webcam feeds on a world map. There are relatively few cameras in mainland China.

1. [RSA and Python](https://xnacly.me/posts/2023/rsa/)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026033113.webp)

A step-by-step explanation of the RSA key algorithm using Python.

1. [Category Theory Illustrated](https://abuseofnotation.github.io/category-theory-illustrated)

![](https://cdn.beekka.com/blogimg/asset/202412/bg2024123101.webp)

An English-language category theory tutorial with lots of illustrations, free to read.

1. [Maxwell's House](https://clerkmaxwellfoundation.org/india-street/housetour.html)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023121716.webp)

A 360-degree virtual tour of the Edinburgh home of James Clerk Maxwell, discoverer of electromagnetic waves. Very finely done.

1. [The Little Book of Linear Algebra](https://github.com/the-litte-book-of/linear-algebra)

![](https://cdn.beekka.com/blogimg/asset/202509/bg2025090712.webp)

A short introductory linear algebra textbook for beginners (in English), with open-source code.
