# Tech Enthusiast Weekly (Issue 435)

## Tools

1. [lazycut](https://github.com/emin-ozata/lazycut)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026031701.webp)

A terminal video-cutting tool built on ffmpeg, allowing you to set start and end points.

1. [PatchMon](https://github.com/PatchMon/PatchMon)

![](https://cdn.beekka.com/blogimg/asset/202510/bg2025103102.webp)

An open-source web application for managing Linux system security patches, supporting multi-user and multi-host environments.

1. [cosmopolitan libc](https://justine.lol/cosmopolitan/)

![](https://cdn.beekka.com/blogimg/asset/202409/bg2024090810.webp)

A C compiler whose output binaries run cross-platform on Linux, macOS, and Windows.

1. [Yaak](https://yaak.app/)

![](https://cdn.beekka.com/blogimg/asset/202409/bg2024091212.webp)

A tool for debugging HTTP, GraphQL, and gRPC requests, similar to Postman.

1. [konty](https://konty.app/)

![](https://cdn.beekka.com/blogimg/asset/202409/bg2024091221.webp)

A cross-platform desktop application for drawing hand-drawn-style wireframes.

1. [lsix](https://github.com/hackerb9/lsix)

![](https://cdn.beekka.com/blogimg/asset/202406/bg2024061509.webp)

An `ls`-like command that displays image file thumbnails directly in the terminal.

1. [NetVentory](https://github.com/RamboRogers/netventory)

![](https://cdn.beekka.com/blogimg/asset/202412/bg2024122610.webp)

A network scanning tool — essentially nmap with a graphical interface.

1. [Speech Note](https://github.com/mkiol/dsnote)

![](https://cdn.beekka.com/blogimg/asset/202409/bg2024091301.webp)

A Linux desktop application that transcribes lecture audio to text and translates it into other languages.

1. [Rustpad](https://github.com/ekzhang/rustpad)

![](https://cdn.beekka.com/blogimg/asset/202409/bg2024091810.webp)

An open-source online text editor supporting real-time collaborative editing of the same document in a browser.

1. [Speed-Test](https://github.com/openspeedtest/Speed-Test)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023121002.webp)

An open-source network speed testing tool supporting all platforms. Since it can be self-hosted, it can also test intranet speeds.

## Resources

1. [Video Game Level Museum](https://noclip.website/)

![](https://cdn.beekka.com/blogimg/asset/202512/bg2025121902.webp)

A website that collects levels from many classic games, converted to WebAssembly so you can preview them in a browser.

1. [Distributed Systems (4th Edition)](https://www.distributed-systems.net/index.php/books/ds4/)

![](https://cdn.beekka.com/blogimg/asset/202411/bg2024111912.webp)

A free downloadable English e-book on distributed systems, revised in 2024.

1. [Email is Easy](https://e-mail.wtf/)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081812.webp)

An online quiz testing your knowledge of email address formats. Twenty addresses are shown; you judge which are valid.

1. [Periodic Table](https://periodictable.com/)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081811.webp)

A website listing each chemical element with a photo, arranged in the layout of the periodic table.

1. [HTML Canvas Deep Dive](https://joshondesign.com/p/books/canvasdeepdive/title.html)

![](https://cdn.beekka.com/blogimg/asset/202406/bg2024061402.webp)

A freely readable English e-book giving a detailed guide to using Canvas to generate graphics on web pages.
