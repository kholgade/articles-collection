# Tech Enthusiast Weekly (Issue 414)

## Tools

1. [passbolt](https://www.passbolt.com/)

   ![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042902.webp)

   An open-source password manager, see [intro article](https://www.xda-developers.com/reasons-why-use-passbolt-manage-passwords/).

2. [Sidequest.js](https://docs.sidequestjs.com/)

   ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081111.webp)

   A Node.js queue task library.

3. [Nerdlog](https://github.com/dimonomid/nerdlog)

   ![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042904.webp)

   A tool for quickly viewing remote server logs in the terminal.

4. [EasyMDE](https://github.com/Ionaru/easy-markdown-editor)

   ![](https://cdn.beekka.com/blogimg/asset/202504/bg2025043003.webp)

   An embeddable Markdown editor for web pages, see [intro article](https://avohq.io/blog/markdown-image-uploads-easy-mde-rails).

5. [Pangolin](https://github.com/fosrl/pangolin)

   ![](https://cdn.beekka.com/blogimg/asset/202504/bg2025042905.webp)

   A reverse tunnel tool that allows access to an intranet server without opening any ports, see [intro article](https://www.xda-developers.com/alternative-to-tailscale-or-nginx-remote-access-home-lab/).

6. [PrivTracker](https://privtracker.com/)

   ![](https://cdn.beekka.com/blogimg/asset/202501/bg2025011803.webp)

   A private tracker service for BitTorrent downloads, can be used to create private torrent files, [open source](https://github.com/meehow/privtracker).

7. [lazy-brush](https://github.com/dulnan/lazy-brush)

   ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025082009.webp)

   A JS library for generating smooth curves with mouse, finger, etc.

8. [perfect-freehand](https://github.com/steveruizok/perfect-freehand)

   ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025082010.webp)

   A web application that supports hand-drawn patterns.

9. [OverType](https://github.com/panphora/overtype)

   ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081810.webp)

   A JS library for an embeddable WYSIWYG Markdown editor in web pages.

10. [ClipCascade](https://github.com/Sathvik-Rao/ClipCascade)

    ![](https://cdn.beekka.com/blogimg/asset/202508/bg2025082007.webp)

    An open-source application for sharing clipboard across different devices. The server can be official or self-hosted, and the client supports various desktop/mobile systems.
