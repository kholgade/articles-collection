# Tech Enthusiast Weekly (Issue 412)

## Tools

1.  [FlyonUI](https://flyonui.com/)

    ![](https://cdn.beekka.com/blogimg/asset/202410/bg2024100504.webp)

    A page component library based on Tailwind CSS.

2.  [endlessh-go](https://github.com/shizunge/endlessh-go)

    ![](https://cdn.beekka.com/blogimg/asset/202403/bg2024032905.webp)

    A tool to defend against malicious SSH login attempts. It does not block the requests but keeps them in a waiting state, increasing the cost for the attacker. It supports Grafana dashboards.

3.  [PuTTYgen](https://puttykeyinfo.com/)

    ![](https://cdn.beekka.com/blogimg/asset/202403/bg2024033001.webp)

    A tool for generating key pairs on the Windows platform.

4.  [gh gfm-preview](https://github.com/thiagokokada/gh-gfm-preview)

    A Go program that creates a service to preview Markdown rendering results.

5.  [vet](https://github.com/vet-run/vet)

    ![](https://cdn.beekka.com/blogimg/asset/202507/bg2025072420.webp)

    A Bash script checking tool. You can use it to run scripts downloaded from the internet; it will tell you what changes the script makes and ask for your approval.

6.  [Krep](https://github.com/davidesantangelo/krep)

    A replacement for the `grep` command, used to search for specific strings in text files. It is said to be 50 times faster than `grep`.

7.  [Inbucket](https://inbucket.org/)

    ![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070709.webp)

    An application for testing email sending functionality. Embed it into your application to test its email sending capabilities, with a built-in web backend.

8.  [Posting](https://github.com/darrenburns/posting)

    ![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070711.webp)

    An HTTP client for the terminal, used to test HTTP requests, similar in functionality to Postman.

9.  [impala](https://github.com/pythops/impala)

    ![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070810.webp)

    A WiFi manager for the Linux terminal.

10. [Tegon](https://github.com/tegonhq/tegon)

    ![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070905.webp)

    An open-source task management system, an alternative to Jira.

## Images

1. [A common urban intersection in the Netherlands](https://bicycledutch.wordpress.com/2018/02/20/a-common-urban-intersection-in-the-netherlands/)

The Netherlands is a cycling nation. To protect cyclists, its intersections are specially designed.

![](https://cdn.beekka.com/blogimg/asset/202411/bg2024112517.webp)

In the image above, the car lanes are in the center, with bicycle lanes on both sides, and a buffer zone between them.

When a car turns, it cannot directly enter the bicycle lane; it must first enter the buffer zone and wait for cyclists to pass, thus avoiding blind spots for drivers.

![](https://cdn.beekka.com/blogimg/asset/202411/bg2024112519.webp)

![](https://cdn.beekka.com/blogimg/asset/202411/bg2024112518.webp)

1. [Soviet space navigation instrument](http://www.righto.com/2023/01/globus-ink-mechanical-navigation.html)

During the development of its space program, the Soviet Union created many unique instruments, perhaps the most peculiar being the navigation instrument.

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120503.webp)

At that time, there was no global navigation system GPS. Inside the instrument was a globe that indicated the current position of the spacecraft.

It was very complex, displaying the spacecraft's position not through electronic components but through mechanical devices.

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120504.webp)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120505.webp)

The globe also had numbered circles from 1 to 8, representing the positions of ground stations communicating with the spacecraft, allowing astronauts to determine which ground station was currently below them.

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120506.webp)

The globe was driven by gears and rotated synchronously with the spacecraft.

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120507.webp)
