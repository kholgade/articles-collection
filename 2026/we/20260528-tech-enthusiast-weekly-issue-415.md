# Tech Enthusiast Weekly (Issue 415)

## Tools

1. [EmbedPDF](https://github.com/embedpdf/embed-pdf-viewer)

![](https://cdn.beekka.com/blogimg/asset/202508/bg2025081813.webp)

A JS library for embedding a PDF reader in web pages.

1. [ArchiveBox](http://archivebox.io/)

![](https://cdn.beekka.com/blogimg/asset/202410/bg2024101703.webp)

A web scraping tool that generates local backups of web pages using the Internet Archive format, with a built-in web frontend.

1. [snitch](https://github.com/karol-broda/snitch)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010314.webp)

A command-line tool that displays programs occupying each port in a user-friendly format in the terminal.

1. [Convert HTML to PNG](https://html2png.dev/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010401.webp)

This website renders HTML code into PNG images for download.

1. [SMTP Tunnel Proxy](https://github.com/x011/smtp-tunnel-proxy)

A network tunneling tool that disguises TCP traffic as email traffic, with both server and client.

1. [Diffs](https://diffs.com/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010715.webp)

A JS library for generating various diff views of code.

1. [Porterminal](https://github.com/lyehe/porterminal)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010315.webp)

A cross-platform network tool for sharing a terminal. After installation, it displays a QR code on the PC terminal; scanning it with a phone allows access to the PC terminal from the phone's browser, not limited to the same local network.

1. [fp-pack](https://github.com/superlucky84/fp-pack)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010402.webp)

A functional programming library for JS/TS, providing various utility functions.

1. [DoNotNotify](https://donotnotify.com/)

![](https://cdn.beekka.com/blogimg/asset/202601/bg2026010601.webp)

An Android app that allows setting text matching rules to filter pop-up notifications on your phone.

1. [Duplicati](https://github.com/duplicati/duplicati/blob/master/README.zh-CN.md)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025051011.webp)

A cross-platform desktop application that backs up local files to various cloud storage via a graphical interface. See [introductory article](https://www.xda-developers.com/finally-started-using-duplicati-should-have-sooner/).

## Resources

1.  [RSA and Python](https://xnacly.me/posts/2023/rsa/)

    ![](https://cdn.beekka.com/blogimg/asset/202603/bg2026033113.webp)

    Explaining the RSA key algorithm step by step using the Python language.

1.  [Category Theory Illustrated](https://abuseofnotation.github.io/category-theory-illustrated)

    ![](https://cdn.beekka.com/blogimg/asset/202412/bg2024123101.webp)

    An English tutorial on category theory with plenty of illustrations, free to read.

1.  [Maxwell's House](https://clerkmaxwellfoundation.org/india-street/housetour.html)

    ![](https://cdn.beekka.com/blogimg/asset/202312/bg2023121716.webp)

    A 360-degree virtual tour of the Edinburgh home of James Clerk Maxwell, the discoverer of electromagnetic waves, exquisitely crafted.

3.  [The Little Book of Linear Algebra](https://github.com/the-litte-book-of/linear-algebra)

    ![](https://cdn.beekka.com/blogimg/asset/202509/bg2025090712.webp)
